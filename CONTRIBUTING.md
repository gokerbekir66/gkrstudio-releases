# Contributing

Thanks for helping make GKR Studio better! This repository only holds the release packages and documentation; the source code is not public, so code pull requests can't be accepted. You can still help a lot:

## Report a bug

1. Update to the latest version first (Settings → Check for updates) and see if the problem is still there.
2. Search the [issues](https://github.com/gokerbekir66/gkrstudio-releases/issues) to see if it was already reported.
3. Open a new issue with the **Bug report** template and include:
   - GKR Studio version (Settings → Updates) and Windows or macOS version;
   - the file type and the wheel slice you used (e.g. PDF → Convert → DOCX);
   - what you expected and what happened, with a screenshot if possible;
   - on macOS, the last lines of `~/Library/Logs/GKRStudio.log`.

Please don't attach private or confidential files. If a file is needed to reproduce the problem, make a small sample without personal data.

## Suggest a feature

Open an issue with the **Feature request** template. Describe what you want to do and why, not only how — that helps find the best way to build it.

## Translations

GKR Studio speaks English, Turkish, Dutch and French. If a text is wrong, unclear or missing in your language, open an issue with a screenshot and the better wording.

## Documentation

Fixes to the README (typos, unclear steps, better screenshots) are welcome as pull requests to this repository.

Please follow the [code of conduct](CODE_OF_CONDUCT.md).
